# KAMP AI — 유압펌프 시점별 이상탐지

GMM 센서 기여와 전류 기록 조건 검토 자료를 공유한다.

공유 자료는 별도 브랜치 [`analysis/gmm-current-audit`](https://github.com/joonookwak/KAMP_ai/tree/analysis/gmm-current-audit/team_shared/gmm_audit)에 정리했다.

- `code/`: 재현 코드
- `results/`: 센서 제거·기존 탐색 결과
- `docs/`: 파이프라인·최신 해석
- `presentation/`: 편집 가능한 최신 PPT

3센서의 높은 점수는 고장 관련 변화와 기록 조건 차이의 기여가  아직 분리되지 않은 결과다. 상세 해석은 공유 자료의 `docs/CURRENT_SENSOR_AUDIT.md`를 따른다.
