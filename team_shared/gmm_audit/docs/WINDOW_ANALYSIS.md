### 최신 결과를 읽는 규칙

**본문 9절·11절의 비교표와 20절은 최신 seed 집계 결과다.** MLP·LSTM·GRU·AE·GMM·IsolationForest는 seed 0·1·2의 평균±표본 표준편차(ddof=1)를 표시한다. 나머지 11방법은 결정론적 1회 결과를 ‘고정’으로 표시한다. 비율의 SD 단위는 퍼센트포인트(%p)다.

12절의 혼동 행렬·FP/FN 분해와 뒤의 상세 W 부록은 **seed=0의 개별 사례**로 유지한다. 0.5초 이내 21/21 등의 정수 사례를 집계 평균과 혼동하지 않는다. 알고리즘 반복은 고장 기록의 독립성을 늘리지 않으며 SD는 일반화 신뢰구간이 아니다.

기존 306개 기록에 seed=1·2의 216개를 추가하여, 결정론적 198개와 확률적 324개를 합친 **522개 실제 실행 결과**를 보존했다. 데이터 분할은 고정했고 각 seed 모델의 임계값은 해당 정상 보정 점수에서 다시 구했다.

## 1. 발표의 핵심 메시지

**유압펌프의 센서 시계열에서 정상 상태를 학습하고, 관측이 들어오는 시점마다 경보를 판단한다. 모델의 분리 능력과 관측을 기다리는 비용을 함께 평가하면, 긴 윈도우나 복잡한 모델이 항상 조기경보에 유리하지는 않다.**

초기 seed=0에서 확인한 결과는 다음과 같다. 최신 비교와 결론은 아래 평균±SD 표와 20절을 함께 읽는다.

- 대표적인 예측·재구축·거리·밀도·경계 기반 17개 방법을 같은 데이터 분할과 경보 규칙으로 비교했다.
- W를 1·2·3·5·8·10·15·20·30으로 넓히고, 자연 운용과 학습부터 통제한 조건에서 총 306조합을 실행했다.
- 자연 운용의 시점별 F1은 GMM·Mahalanobis에서 W=3, LSTM·GRU에서 W=8이 가장 높았다. W를 계속 늘려도 성능이 계속 상승하지 않았다.
- GMM W=2는 이상 기록의 21클립 모두에서 시작 후 0.5초 이내 경보했고, 정상 120클립 중 2클립에서 경보했다.
- 긴 W는 공통 후반 시점의 분리에는 도움이 될 수 있지만 초기 대기와 짧은 클립 손실을 만든다. W=30의 최초 판단은 3초다.

이는 한 이상 기록에서 수행한 탐색 비교다. 독립적인 고장 21건에 대한 검증 결과나 새로운 고장 발생 전 예측 성공을 의미하지 않는다.

## 2. 문제 정의와 해결하려는 현장 문제

### 2.1 과제 배경과 요구사항

사용자가 데이터 폴더의 `readme.md`에 정리한 과제 요구사항을 기준으로 한다. 파인블랭킹 프레스의 유압펌프 이상은 압력 불안정, 가공품 불량, 설비 비가동으로 이어질 수 있다. 모터의 상부·하부 진동과 전류 시계열을 활용해 초기 이상을 탐지하고, 정상 운전 변화를 고장으로 오인하는 오경보와 미탐 발생 조건을 분석하는 것이 목적이다.

본 실험의 목표는 **현재 관측까지의 센서값만 이용하여, 기록 구간이 시작된 뒤 얼마나 빨리 이상 경보를 낼 수 있는지** 비교하는 것이다. 결과물을 확인한 뒤 판정하는 방식보다 센서 관측 단계에서 경보를 제공하는 방향이다.

### 2.2 현재 데이터로 평가할 수 있는 범위

| 구분 | 본 실험에서의 의미 |

| 조기경보 | 이상 라벨 클립의 시작부터 첫 경보까지의 시간을 측정 |

다만 이상 데이터는 개발 과정에서 이미 시각화하고 여러 방법을 비교했다. 학습에 이상을 넣지 않았다는 사실과 테스트가 완전히 미공개인 독립 검증이라는 주장은 다르다. 현재 결과는 탐색 실험으로 표시한다.

## 5. 온라인 판단과 W의 정확한 의미

센서 관측을 `z_0,z_1,…`로 표시한다. W는 **현재 시점을 판단하기 위해 사용하는 과거 관측 개수**다. 첫 관측의 인덱스는 0이다.

| 판단 방식 | 시점 t에서의 입력과 점수 |
|---|---|
| 예측 | 과거 `z_(t−W)…z_(t−1)`로 현재 `z_t`를 예측한 뒤, 현재 관측이 도착하면 오차 계산 |
| 재구축·거리·밀도·경계 | 과거 W개와 현재 `z_t`를 합친 관측 벡터를 직접 점수화 |
| RobustMAD | 현재 세 센서값만 점수화하는 정적 기준선 |

W=2의 예:

1. 0.0초와 0.1초의 관측을 모은다.
2. 0.2초의 관측이 들어오면 첫 점수를 계산한다.
3. 0.3초에는 과거 0.1·0.2초를 이용하여 다시 판단한다.
4. 매 0.1초마다 반복하며 미래 시점이나 클립 끝값은 보지 않는다.

예측 입력 W개 자체의 첫 값~마지막 값 시간 범위는 `(W−1)×0.1초`다. 최초 판단까지의 대기는 `W×0.1초`이며, 재구축/분포 입력은 현재까지 W+1개다. 예측을 W초 이후로 멀리 수행하는 방식은 아니다. 예측 horizon은 다음 한 시점이다.

학습·평가 stride는 모두 1이다. LSTM·GRU는 창마다 은닉 상태를 초기화하며 클립 경계를 넘어 정보를 전달하지 않는다. 서로 다른 알고리즘을 같은 형태의 내부 모델로 만든 것은 아니지만, **판단 시점에 이용 가능한 정보와 미래 정보 금지 규칙**을 맞췄다.

## 6. 공통 이상 점수 → 경보 → 평가 파이프라인

`CSV 점검 → 중복 제거 → 공백 기준 클립 분리 → 클립별 시간 분할 → 정상 학습 정규화 → 창 생성 → 정상 모델 학습 → 정상 보정 점수 → 임계값 → 테스트 시점별 True/False → 시점 지표와 첫 경보 집계`

| 단계 | 공통 규칙 |
|---|---|
| 이상 점수 | 방법마다 정의는 다르지만 클수록 이상으로 통일 |
| 임계값 τ | 정상 보정의 판단 가능한 시점 점수 99백분위수 |
| 시점 경보 | `점수 > τ`이면 True, 같거나 작으면 False |
| 자연 운용 준비 구간 | 클립 처음 W개 시점은 점수를 만들 수 없으므로 False |
| 짧은 클립 | 길이가 W 이하이면 전체 판단 불가, 전체 시점 평가에는 유지 |
| 경보 유지 | 한 번 경보했다고 이후 시점을 모두 True로 채우지 않음 |
| 정답 소급 보정 | 정답을 보고 앞뒤 구간을 True로 바꾸는 point adjustment를 하지 않음 |

99백분위수는 정상 보정 점수에서 약 1% 꼬리를 경보 대상으로 삼는 정책이다. 시간 상관·분포 변화가 있으므로 미래 테스트 시점 오탐률 1%를 보장하는 것은 아니다. sklearn의 자동 contamination/기본 0 경계를 경보 임계값으로 사용하지 않는다.

서로 다른 방법의 점수 숫자를 직접 비교하지 않는다. 재구축 MSE, 거리, 음의 로그밀도는 척도가 다르므로 각자의 정상 보정 기준으로 경보로 변환한 후 비교한다.

### 7.1 점수 정의

- 예측: `s_t = 세 센서의 (정규화 현재값−예측값)² 평균`.
- PCA/AE 재구축: `s_t = 과거 W개+현재값의 전체 좌표 재구축 제곱오차 평균`. 현재 세 센서만의 재구축 오차와는 다르며 창 전체를 복원한다.
- Mahalanobis: `s_t = (v_t−μ)ᵀ Σ⁻¹ (v_t−μ)`. `v_t`는 과거와 현재를 펼친 벡터다. 센서 간·시차 간 공분산을 고려한다.
- GMM: `s_t = −log Σ_k π_k N(v_t | μ_k,Σ_k)`. 정상 혼합 분포에서 드문 관측일수록 점수가 크다.
- KDE: 정상 kernel 합으로 구한 밀도의 음의 로그값.
- LOF: 정상 이웃 대비 국소 밀도 차이. 보정·테스트를 학습 이웃에 추가하지 않는다.
- RobustMAD: `max_j |(현재값_j−정상 중앙값_j)/(1.4826×MAD_j)|`.

AR_Relation은 실제 다음 전류를 입력하지 않는다. AR로 예측한 전류를 사용해 보정하므로 미래 관측 누수를 막는다. 변수 관계 회귀는 예측적 관계를 다루며 물리적 인과관계를 증명하지 않는다.

신경망은 seed 0·1·2, Adam, 학습률 0.001, 배치 128, 최대 150epoch, 정상 검증 기반 patience 15를 사용했다. LSTM·GRU·AE는 gradient clipping 1과 weight decay 1e-4를 사용한다. AE bottleneck은 `max(2,min(8,dim//4))`다. MLP·LSTM·GRU·AE·GMM·IsolationForest는 seed 0·1·2 반복을 완료했다. 각 실행에서 정상 검증 조기 종료·정상 보정을 독립적으로 적용한다.

## 8. 평가지표: 시점 판정과 조기경보를 구분

### 8.1 주 결과: 모든 테스트 타임스탬프

정상 4,090 + 이상 600 = **4,690시점**이 모든 자연 운용 방법의 공통 분모다.

| 실제 라벨 | 경보 True | 경보 False |
|---|---|---|
| 이상 1 | TP: 탐지 | FN: 미탐 |
| 정상 0 | FP: 오탐 | TN: 정상 판정 |

- Precision = TP/(TP+FP)
- Recall = TP/(TP+FN)
- F1 = 2TP/(2TP+FP+FN)
- 시점 오탐률 = FP/(FP+TN)
- 시점 미탐률 = FN/(TP+FN)

초기 준비 구간을 제외하지 않는다. 그 시점에 아직 경보를 못 냈다는 운용 비용으로 정상은 TN, 이상은 FN에 포함한다. 길이가 짧아 한 번도 판단하지 못한 클립도 평가에서 버리지 않는다. 준비 구간을 제외한 성능은 보조 값으로 별도 구분한다.

## 20. Seed 반복 실험: 평균 ± 표준편차와 최신 해석

## Seed 0·1·2 반복 실험: 평균 ± 표준편차

상태: 완료. 독립 실행 기록 522/522개. 기존 seed=0 기록을 유지하고 seed=1·2의 216조합을 추가 학습했다.

### 반복이 필요한 방법과 집계 규칙

| 방법 | 반복 | 변동 원인 |
|---|---|---|
| MLP32·LSTM32·GRU32·AE_Recon | seed 0·1·2 각각 학습 | 가중치 초기화·배치 순서 |
| GMM | seed 0·1·2, 각 실행 n_init=2 유지 | 혼합 분포 초기화·국소 최적해 |
| IsolationForest | seed 0·1·2 | 학습 샘플링·무작위 분할 |
| Persistence·AR·VAR_Ridge·AR_Relation | 1회 | 본 구현은 고정된 데이터의 결정론적 예측·닫힌해 ridge |
| PCA_Recon·Mahalanobis·kNN20·KDE·LOF20·OCSVM·RobustMAD | 1회 | full SVD·공분산 추정·이웃/밀도/경계 계산은 본 설정에서 결정론적 |

- 평균과 표준편차는 각 seed의 지표를 먼저 구한 뒤 집계한다. 평균 혼동 행렬에서 F1을 다시 계산하지 않는다.
- 표준편차는 표본 표준편차 s=√[Σ(metric−평균)²/(3−1)], ddof=1이다. 단위가 비율이면 평균은 %, SD는 퍼센트포인트(%p)로 표기한다.
- 결정론적 방법은 반복하지 않고 `고정`으로 표기한다. 단일 실행을 세 번 복제해 SD=0으로 제시하지 않는다.
- 데이터 분할·정규화·W·학습 규칙은 고정한다. 각 seed의 임계값은 그 seed 모델의 정상 보정 점수 99백분위수에서 다시 계산한다.
- seed=0은 이미 저장된 동일 프로토콜의 W 확장 결과를 재사용했다. seed=1·2의 원본 판정·학습 기록·모델은 별도 폴더에 보존한다.
- 각 seed를 독립 고장 사례로 취급하지 않는다. SD는 동일 데이터에서 알고리즘 초기화/샘플링에 따른 변동이며 일반화 신뢰구간이 아니다.
- 테스트 F1로 가장 좋은 seed를 골라 보고하지 않는다. 세 seed 모두 포함한다. W별 평균 최고값도 탐색 관찰이며 최종 W 선정과 구분한다.

### 데이터와 해석 범위

- 자연 운용은 정상 4,090+이상 600=4,690시점 전체를 평가하고 준비 구간은 경보 없음으로 남긴다.
- 공통 시점은 index≥30인 정상 1,135+이상 146=1,281시점이다. 이상 10클립만 남으므로 이 결과의 높은 F1은 전체 조기경보 성능이 아니다.
- 각 seed에서도 정상 클립 경보 예산을 동일하게 맞춘 것은 아니다. 임계값 산출 규칙이 같다는 것과 작업 중단 빈도가 같다는 것은 다르다.
- 기록이 정상/이상 날짜 각각 하나이고 이상 21클립이 한 기록에서 나온 제한은 반복 seed로 해소되지 않는다.
- 상세 CSV: `seed_experiments/seed_runs.csv`·`seed_summary.csv`. 원본 경로·해시: `seed_sources.json`. 원본 seed=0은 `window_sweep/{natural,controlled}/results`, seed=1·2는 `seed_experiments/{natural,controlled}/seed_{1,2}/results`.

#### 핵심 요약과 현재 후보

W를 늘리면 과거 정보가 많아져 분리 능력이 개선될 수 있지만, 최초 판단이 늦어지고 짧은 클립에서 판단하지 못하는 비용도 증가한다. 따라서 전체 운용 성능은 W에 따라 계속 증가하지 않는다.

- 운용 F1의 관측 최고점: GMM·Mahalanobis W=3, LSTM·GRU W=8. 이는 현재 테스트 데이터의 탐색 결과이며 최종 W를 테스트 F1로 선택했다는 뜻은 아니다.
- 조기경보 후보는 GMM W=2·3을 유지한다. W=2는 0.5초 이내 21/21클립, W=3은 20/21클립에서 경보했다. 정상 경보 클립은 둘 다 2/120이었다.
- W=30은 최초 판단이 3초이고 이상 600시점 중 454시점이 준비 구간이다. GMM이 나머지 시점을 모두 맞혀도 전체 F1의 최대값은 0.391이다.
- 통제 비교에서는 학습·검증·보정·평가의 타겟을 모두 같게 맞췄다. 이 비교는 긴 이력의 정보 효과를 보여주지만, 후반의 긴 클립에 한정된다.
- 최종 후보 비교 기준은 시간별 누적 탐지율·끝까지 미탐 비율·정상 클립 경보율을 함께 사용한다. 시점별 F1·오탐률·미탐률도 계속 주 결과로 기록한다.
- 남은 비교 조건은 정상 클립 경보 예산이다. 정상 보정 99백분위수 규칙이 같아도 작업 중단 빈도가 같지는 않으므로, 별도 정책 실험에서 예산을 통일한다.

#### 해석

- 범위를 넓히자 운용 F1의 최고점이 확인됐다. GMM W=3은 0.928, Mahalanobis W=3은 0.923, LSTM W=8은 0.804, GRU W=8은 0.783이었다. 적어도 이 방법들은 끝값 W=30에서 최고가 아니며 단조 증가하지 않았다.
- GMM W=2는 0.5초 내 21/21, W=3은 20/21을 탐지했고 정상 경보 클립은 둘 다 2/120이었다. W=3의 높은 시점 F1과 W=2의 빠르고 넓은 조기경보는 다른 장점이다.
- 학습부터 통제한 C에서는 GMM F1이 W=1 0.696 → W=3 0.997 → W=5 1.000으로 개선됐으나 이후 일관된 추가 상승은 없었다. 평가 대상은 후반의 146 이상 시점뿐이다.
- LSTM은 C에서 W=1 0.580 → W=20 0.969로 올라가고 W=30 0.940으로 내려갔다. 긴 이력의 분리 효과는 있으나 운용 평가에서는 기다리는 비용 때문에 W=8이 더 높았다.
- GMM W=30의 운용 F1 0.391은 준비 구간을 포함한 이론적 최대 F1과 같다. 판단 가능한 시점은 완벽하게 분리했지만 너무 늦게 시작해서 전체 이상 600시점 기준의 성능이 낮아진 사례다.
- W가 커질수록 최초 판단의 하한 W×0.1초는 늦어진다. 더 큰 W가 더 빠른 최초 경보를 보장하지 않는다.
- 정상 이력으로 분리 성능이 개선될 수 있지만 실제 운용 F1은 긴 대기와 짧은 클립 손실 때문에 떨어질 수 있다. A와 C가 답하는 질문이 다르다.
- 정상 보정 임계값 규칙은 99백분위수로 같지만 정상 테스트의 클립 경보율이 같다는 보장은 없다. 동일 작업 중단 예산 비교는 별도 경보 정책 실험으로 다뤄야 한다.
- 낮은 지연 중앙값을 단독으로 최적화하면 놓친 클립을 숨길 수 있다. 시간별 누적 탐지율은 계속 21클립을 분모로 유지한다.
- C에서 과거를 쓰지 않는 RobustMAD와 직전값만 쓰는 Persistence의 점수가 모든 W에서 같음을 확인했다. 학습·평가 표본 통제가 실제 작동하는 확인 기준이다.
- 모델 설정은 정상 데이터로 정했고 테스트 F1로 모델을 재튜닝하지 않았다. 표의 가장 높은 테스트 값은 탐색 결과이며 최종 W 선정 근거와 분리해야 한다.
- 이상 21클립은 한 기록이고 초기 상세 사례는 seed=0다. 공통 후반 시점의 높은 F1을 전체 고장 일반화나 0.2초 조기탐지 성능으로 해석하지 않는다.

## 21. 최신 센서 검토와 발표자료



전류를 포함한 높은 탐지 성능은 확인됐지만, 전류의 고장 관련 변화와 기록 조건 차이의 기여를 현재 데이터만으로 분리하기 어렵다. 전류 단독 성능이 높다는 사실만으로 누수를 확정하지 않는다. 진동만 결과를 전류 기록 차이의 영향을 줄인 보수적 비교 기준으로 설명하며, 이 결과도 현장 고장 탐지 성능을 보장하지 않는다.
